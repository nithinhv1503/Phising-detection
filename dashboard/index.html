📐 System Architecture & Research Methodology

1. Multi-Tiered Detection Pipeline

The system employs a fast two-tiered hybrid architecture: Tier 1 executes sub-millisecond threat reputation lookups against synchronized threat databases and a verified whitelist. Tier 2 extracts a 25-dimensional lexical, structural, and information-theoretic (Shannon entropy) feature vector, passing it to an optimized Random Forest ensemble classifier with explainable feature attribution.

2. Manifest V3 Real-Time Browser Extension

The browser client utilizes the Chrome Extensions Manifest V3 service worker API (chrome.webNavigation.onBeforeNavigate) to intercept navigation events prior to sensitive user input, providing an active interstitial warning screen for zero-day phishing protection.

3. Key Performance Achievements

  • Accuracy: >98.6% on held-out multi-source test datasets.
  • Sub-10ms Inference: Optimized tree serialization and vectorization guarantee instant browsing responses.
  • Explainable AI (XAI): Transparent risk breakdown explaining exact factors (e.g. brand spoofing, IP hosting, abusive TLDs).
